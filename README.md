# RC Drift Dash

Гонка на время для Meta Quest 3S / Quest 3. Откройте проект в Unity **6000.3.7f1** и сцену **Assets/RCDriftDash/Scenes/MR_Race.unity**. Она включена в сборку. QuestCheck оставлена для отдельной диагностики.

## Заезд на гарнитуре

1. Настройте пространство комнаты в системном меню Quest, включая пол и стол. При запуске разрешите приложению доступ к пространственным данным. В режиме passthrough наведите правый контроллер на пол или стол. Зелёный предпросмотр означает, что трасса 1 × 1 м помещается с запасом. Нажмите **A**, чтобы её закрепить. Если данные комнаты недоступны, после настройки пространства нажмите **B** для повторной загрузки.
2. Поднесите левую руку к рулю, правую — к пульту. Удерживайте боковые кнопки хвата. Поставьте руль прямо и отпустите курок. Выберите **Старт** правым лучом и **A**. После отсчёта правый курок задаёт газ, поворот левого запястья вокруг оси руля — направление.
3. Езжайте по стрелкам через ворота 1–7 и клетчатый финиш. Время засчитывается после правильной последовательности и направления пересечений. Лучший круг хранится локально для этой трассы, версии правил и числа кругов.
4. **B** или отпускание предмета ставит заезд на паузу. Возьмите оба предмета, верните руль в нейтраль, отпустите газ и подтвердите продолжение. Время на паузе исключается. **На старт** сбрасывает попытку, **Переставить** возвращает к выбору поверхности.

## Проверка без шлема

В редакторе с выключенным настольным XR откройте MR_Race, нажмите Play и щёлкните во вкладке Game, чтобы она получила ввод. **Enter** устанавливает трассу, **G** берёт оба предмета, следующий **Enter** запускает отсчёт. **W** — газ, **A/D** — руль, **P** — пауза, **R** — сброс попытки. Кнопки панели также доступны мышью. Этот режим использует условную поверхность в редакторе.

## Сборка

Установите для 6000.3.7f1 модули Android Build Support, SDK & NDK Tools и OpenJDK. В File → Build Profiles выберите Android → Switch Platform. Включите Developer Mode на Quest, подключите шлем по USB и подтвердите отладку в гарнитуре. В Run Device выберите шлем, затем Build And Run. Путь для APK — Builds/RCDriftDash.apk. Идентификатор приложения — com.rcdriftdash.prototype.

## Настройки

На объекте Race systems задаётся число кругов. На ControlsRoot можно поменять руки и рабочий угол руля. Параметры тяги, скорости и руления находятся на CarRoot. Геометрия, материалы и синтезированные игровые звуки созданы для этого проекта. Модели контроллеров поставляются с Meta XR Core SDK. Доступ к комнате обеспечивает Meta MR Utility Kit 83.0.4.
